# 📝 Neon Notes App

A simple and responsive Notes Application built with **Node.js**, **Express.js**, **EJS**, and **Tailwind CSS**.

## ✨ Features

- Create Notes
- View Notes
- Delete Notes
- Responsive UI
- File System (FS) Storage

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- Tailwind CSS
- JavaScript
